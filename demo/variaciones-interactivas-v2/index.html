Antes / Después

El F1 v1 usaba un estilo propio (paleta GitHub-dark, tipografías ajenas). El v2 se dibuja con el design system real — mismas variables, mismos temas.

Guía de decisión

PantallaRecomendadoPor quéSi prefieres…
Home desktop A · Estado de un vistazo Resume sin robar protagonismo a las secciones; cada cifra enlaza. B si quieres actuar nada más abrir; C si vigilas el sistema a diario.
Home móvil B · Urgencias primero En móvil entras a resolver, no a pasear; el launcher queda debajo. A si el uso real es de salto entre secciones; C si quieres flujo tipo feed.
Lateral B · Fijo + temporal El trabajo de la semana vive en el lateral sin quedarse para siempre; caducidad visible. A si valoras orden estable ante todo; C si quieres control total con catálogo.
Cómo responder: en Decisiones, con tu mix — por ejemplo «Home A · Móvil B · Lateral B» — o eligiendo una de las opciones preparadas (mix recomendado, actuar rápido, profundidad, o por pantalla). Con tu OK se abre el F2 de implementación con tests.

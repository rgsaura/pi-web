# UI Design & Development Manifesto — Exohuman Web (Pi Web)

## Principio Rector: UX Radical y Densidad de Valor
La interfaz existe para amplificar la mente y el foco de Rodrigo, no para enseñarle los engranajes del motor.

## Criterios Obligatorios de Interfaces en ExoHuman UI (Rodrigo, 2026-10-16)
1. **Centralización Total**:
   - Cero servidores web efímeros, puertos dispersos ni HTMLs huérfanos fuera del sistema.
   - Cualquier pantalla, visor o herramienta vive como una vista nativa de primer nivel dentro de ExoHuman UI.

2. **Funcionalidad Real (Action-Oriented)**:
   - Toda interfaz debe servir para actuar: aprobar decisiones en 1 clic, abrir sesiones de trabajo vivas, pausar o activar rutinas y lanzar tareas.
   - Prohibidas las pantallas meramente decorativas o de solo lectura estática cuando hay acciones asociadas.

3. **Veracidad y Estado Real (Observable)**:
   - Prohibido inventar datos, barras de progreso o porcentajes arbitrarios.
   - Si una tarea está en curso, se muestra el estado vivo y el link directo a la sesión de trabajo.

4. **Experiencia Móvil de Primer Nivel (iOS Safari & PWA)**:
   - Respeto estricto a las safe-areas superior e inferior, status bar integrada (`black-translucent`), targets táctiles cómodos (>34px) y navegación sin desbordamientos.
